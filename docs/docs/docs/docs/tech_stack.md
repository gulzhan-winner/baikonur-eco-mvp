# Technology Stack

## Hardware
- ESP32 DevKit V1
- DHT11 (Temperature, Humidity)
- HC-SR04 (Distance / Container fill level)
- SR505 PIR (Motion detection)
- HSD (Sound level)
- HYDZ (Rain / water detection)

## Software
- Arduino IDE
- C/C++ (ESP32 firmware)
- WiFi (ESP32 network connection)
- Telegram Bot API (User notifications)
- UniversalTelegramBot library
- ArduinoJson library

## AI Layer
- Rule-based decision system (risk scoring)
- Output classification: LOW / MEDIUM / HIGH

## Repository Structure
- firmware/ — source code (ESP32 + simulation)
- docs/ — technical documentation
- pitch/ — presentation file (Pitch-deck)
- media/ — diagrams, screenshots, video assets
