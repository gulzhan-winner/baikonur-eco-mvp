# Baikonur Eco AI Monitoring System (MVP)

Интеллектуальная система мониторинга экологии для района космодрома Байконур.

Проект разработан как MVP (Minimum Viable Product) для научного конкурса в области космической экологии, IoT и искусственного интеллекта.

---

## Проблема

Запуски ракет и эксплуатация космодромов могут сопровождаться загрязнением окружающей среды:
- распространение пыли и продуктов сгорания
- изменение климатических параметров
- отсутствие оперативного экологического мониторинга

Существующие решения дорогие и не предназначены для локального автоматического контроля.

---

## Решение

Предлагается прототип интеллектуальной системы, которая:

- собирает данные с датчиков окружающей среды
- анализирует их с помощью AI-логики
- уведомляет пользователя через Telegram-бота
- моделирует процесс сбора радиационной пыли

Система может быть использована для мониторинга экологической ситуации в районе космодрома Байконур.

---

## MVP (Minimum Viable Product)

Текущая версия MVP включает:

- ESP32 микроконтроллер
- Telegram-бот
- датчик температуры и влажности (DHT11)
- ультразвуковой датчик (HC-SR04)
- PIR-датчик движения (SR505)
- датчик звука (HSD)
- датчик воды/дождя (HYDZ)
- AI-логика оценки экологического риска

При отсутствии оборудования используется симуляция датчиков.

---

## Архитектура системы

Датчики → ESP32 → Telegram Bot → AI анализ → Пользователь

Система построена на основе IoT-архитектуры.

---

## AI-логика (упрощённая)

Система анализирует:
- температуру
- влажность
- уровень шума
- движение
- наличие осадков
- уровень заполнения контейнера

На основе этих параметров вычисляется экологический риск:
- LOW
- MEDIUM
- HIGH

Это rule-based AI, который может быть расширен до ML-модели.

---

## Команды Telegram-бота

/start — запуск системы  
/status — текущие показатели датчиков

## Запуск проекта

1. Подключить ESP32
2. Загрузить прошивку через Arduino IDE
3. Подключить Wi-Fi
4. Запустить Telegram-бот
5. Отправить команду /start
